# Шифр вертикальной перестановки

Программа реализует шифр вертикальной перестановки с 5 столбцами.

## Компиляция

```bash
make
```

## Использование

### Шифрование
```bash
./cipher -e <входной_файл> <выходной_файл>
```

### Расшифрование
```bash
./cipher -d <входной_файл> <выходной_файл>
```

## Формат ключа

Ключ хранится в файле `key.txt` и представляет собой перестановку чисел 0-4.

Пример (текущий ключ):
```
3 1 4 0 2
```

Это означает:
- Сначала читается столбец 3
- Затем столбец 1
- Затем столбец 4
- Затем столбец 0
- Затем столбец 2

## Принцип работы

1. **Шифрование:**
   - Текст записывается построчно в таблицу с 5 столбцами
   - Если длина не кратна 5, добавляются символы 'z'
   - Затем читается по столбцам в порядке, заданном ключом

2. **Расшифрование:**
   - Обратная операция: восстановление исходного порядка

## Пример

Для текста "Hello World! This is a test message." и ключа [3, 1, 4, 0, 2]:

Исходный текст разбивается на строки по 5 символов:

Затем читается по столбцам в порядке ключа, получается зашифрованный текст.
